# DT4H_AI4HF_contributions
Contributions to the DT4H and AI4HF consortia.

## Data preprocessing examples
This repo currently contains an R file with a function that walks through some preprocessing steps.

An important part of the preprocessing is imputation. Some additional resources that may be useful are listed below:
* https://search.r-project.org/CRAN/refmans/mice/html/mice.html
* https://github.com/amices/mice/tree/master
* https://stefvanbuuren.name/fimd/ chapters 1.4 and 5.
